## 🌟 نظرة عامة
برنامج **ASM Download Manager (ADM) — Windows 7 Edition** هو إصدار خاص ومُحسّن بالكامل ليعمل بأعلى كفاءة وسرعة استثنائية على أنظمة **Windows 7 Service Pack 1** وما بعدها، بنواتي **32-bit (x86)** و **64-bit (x64)**.

تم بناء البرنامج بمحرك حركي أصلي مستقل يوفر سرعات تحميل مضاعفة تصل إلى أقصى حد يتحمله اتصالك، مع دعم كامل لاستئناف التحميل، التقاط الروابط، تحميل ملفات الفيديو والصوت من الإنترنت، وتحميل التورنت دون أي استهلاك زائد لموارد النظام أو الذاكرة.

## 🚀 المميزات الرئيسية

* **محرك توربو متعدد المسارات (Multi-Threaded Turbo Engine):**
  تقسيم ديناميكي ذكي للملف إلى أجزاء متعددة لزيادة سرعة التحميل إلى أقصى طاقة للشبكة.
* **دعم كامل لأنظمة ويندوز 7 بنواتيها:**
  بنية مخصصة لنواة 32-bit (x86) ونواة 64-bit (x64) بدون الحاجة لتثبيت بيئات تشغيل إضافية ثقيلة.
* **استئناف التحميل الذكي (Smart Resume):**
  استئناف التحميلات المتوقفة بسبب انقطاع الإنترنت أو إغلاق النظام مع دعم كامل لتجديد الروابط منتهية الصلاحية.
* **أداة تحميل الفيديوهات وقوائم التشغيل (Video & Playlist Downloader):**
  تحميل الفيديوهات بأعلى جودة متاحة وتحويلها واستخراج المقاطع الصوتية بصيغة M4A و MP3، مع ميزة تحميل قوائم التشغيل دفعة واحدة.
* **مقتنص المواقع الشامل (Site Grabber):**
  فحص أي صفحة ويب وتنزيل جميع الوسائط والصور والملفات والمستندات الموجودة بها بنقرة واحدة.
* **دعم ملفات التورنت و Magnet:**
  تحميل ملفات التورنت والروابط المغناطيسية مباشرة داخل البرنامج دون الحاجة لبرامج إضافية.
* **جدولة التحميلات وتحديد السرعة (Scheduler & Speed Limiter):**
  تنظيم طوابير التحميل وتحديد مواعيد البدء والإيقاف، مع إمكانية تحديد سرعة التحميل للحفاظ على تصفح سلس.
* **واجهة عصرية خفيفة وسريعة (Modern Lightweight UI):**
  واجهة مريحة ومصممة بأناقة مع دعم الوضعين المظلم والفاتح، واستجابة فائقة السرعة واستهلاك ضئيل للذاكرة والمعالج.
* **تحديثات تلقائية ذكية (Self-Updating):**
  البرنامج يتحقق تلقائياً من الإصدارات الجديدة المتوافقة مع معمارية جهازك ويقوم بالتحديث بسلاسة وأمان.
